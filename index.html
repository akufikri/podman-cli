Features

Everything you reach for in podman — one screen, one keypress away.

#1 Manage

Containers

Start, stop, restart, read logs or remove — pick a container, hit Enter, choose an action.

#2 Pull

Images

Pull or update images, remove the stale ones, or run a container straight from an image.

#3 Create

New Container

A form for image, name, ports, volumes, env, restart and command — Enter runs podman run -d.

#4 Organize

Pods, Volumes, Networks

Each resource gets its own section with live counts. Every remove asks y/n first.

#5 Trace

Built-in Logging

Every podman call is logged with exit code and duration — and readable from the Logs menu.

#6 Adapt

Responsive Layout

Works in small split panes. Panels collapse as the terminal shrinks and re-layout on resize.

Install

Three commands to run. One more to use it from anywhere.

00 · Requirements

  • →podman on your PATH
  • →bun 1.4.x
  • →A running Podman machine (press m to start it)
01 · Clone & run 
git clone https://github.com/akufikri/podman-cli.git
cd podman-cli
bun install
bun start
02 · Global command
bun link      # once
podman-cli    # from any directory

FAQs

Read the README ↗
I get “Failed to initialize OpenTUI render library”. +

Your shell is picking up an older Bun. OpenTUI needs Bun 1.4.x — check which bun and make sure the newer install comes first on your PATH.

The list looks empty. +

Usually the terminal is too short or narrow. Enlarge the window or zoom out — the layout adapts and hides the Details panel first.

My Podman machine is stopped. +

The TUI shows a warning and an m key. Press it to start the machine without leaving the dashboard.

Where are the logs stored? +

In ~/.local/state/podman-cli/podman-cli.log (or under $XDG_STATE_HOME). Press 7 to read them inside the TUI.

Can I use it without the TUI? +

Yes. The typed wrapper runs standalone, e.g. bun src/podman.ts containers.
